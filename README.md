# YDST 2026 — YourDegree Scholarship Test (prototype)

Draft prototype of an always-open, AI-proctored scholarship test (MAH MBA CET pattern). Not an official offer.

- `index.html` — landing page
- `exam.html` — exam prototype: registration, demo (20 Q) or full (200 Q) paper, timer, question palette, simulated proctoring, result and scholarship code

Prototype only: answers are checked in the browser and attempt limits are stored in localStorage. Production needs server-side scoring, OTP verification and a real proctoring service.
