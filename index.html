Eligibility and rules

Simple rules that keep the scholarship fair for everyone.

  • Open to new applicants to any Online CU program
  • One attempt per month, with a fresh set of questions each time
  • Scholarship code valid for 30 days, for the current intake
  • Covers 50% of first-semester tuition for the program you tested for
  • Can't be combined with any other discount or offer
  • Doesn't cover registration, exam or other fees
  • Not transferable to another program or person
  • Unfair means flagged by proctoring void the scholarship

Frequently asked questions

Anything else? Our admissions counsellors are happy to help.

Is the test really free?

Yes. There is no fee to register or take the test.

What do I need to take the test?

A laptop or desktop with a webcam and microphone, a stable internet connection, and 150 minutes in a quiet room. The test runs in full screen and is AI-proctored.

Is there negative marking?

No. Each correct answer carries 1 mark and wrong answers carry no penalty, so attempt every question.

What if I don't score 170?

You can try again next month with a new set of questions. You can also apply to your program at any time. Our counsellors will help you with your options.

What if my internet disconnects?

Your answers are saved as you go. Reconnect within 5 minutes to continue. After that, the attempt counts as used.

Can I use my code for a different program?

No. The code is valid only for the program you chose before the test.

How long is my scholarship code valid?

30 days from the day you qualify, for the current intake.
